# โยธาแคด สำหรับ Windows (YothaCAD Desktop)

โปรแกรมเขียนแบบอาคาร 2D / 3D แบบติดตั้งบน Windows ห่อจากโยธาแคดเวอร์ชันเว็บด้วย Electron
**ใช้งานออฟไลน์ได้ทั้งหมด** (Three.js, ExcelJS และฟอนต์ไทยอยู่ในตัวโปรแกรม)

| ความสามารถ | รายละเอียด |
|---|---|
| ไฟล์ติดตั้ง | `YothaCAD-Setup-x.y.z.exe` มีไอคอนในเมนู Start, เดสก์ท็อป และทาสก์บาร์ |
| ไฟล์งาน `.ycad` | บันทึก / บันทึกเป็น / ดับเบิลคลิกไฟล์เพื่อเปิดโปรแกรม / รายการไฟล์ล่าสุด / กู้คืนงานเมื่อโปรแกรมปิดไม่ปกติ |
| เมนู Windows | ไฟล์ · แก้ไข · มุมมอง · หน้าต่าง · ช่วยเหลือ พร้อมปุ่มลัด (Ctrl+S, Ctrl+O, Ctrl+N …) |
| หลายหน้าต่าง | Ctrl+Shift+N หรือคลิกขวาไอคอนบนทาสก์บาร์ → หน้าต่างใหม่ |
| ส่งออก | PDF, DXF, Excel BOQ, IFC, CSV, PNG, สคริปต์ Revit — เลือกโฟลเดอร์ได้ หรือตั้งให้บันทึกลงโฟลเดอร์ประจำโดยไม่ถาม |
| นำเข้า | ไฟล์ `.json` ที่ส่งออกจากเวอร์ชันเว็บ (ไฟล์ → นำเข้าโครงการจากเวอร์ชันเว็บ) |
| อัปเดตอัตโนมัติ | build เป็นฉบับร่างให้ทดสอบก่อน → กด Publish แล้วเครื่องผู้ใช้จึงได้รับแจ้งเมื่อเปิดโปรแกรม |

## โครงสร้างโฟลเดอร์

```
yotha-cad-desktop/
├─ web/                    ← ★ วางไฟล์ HTML ของโยธาแคดเวอร์ชันเว็บที่นี่ (ไฟล์เดียว ชื่ออะไรก็ได้)
├─ src/
│  ├─ main.js              โปรแกรมหลัก: หน้าต่าง เมนู ไฟล์ .ycad ส่งออก
│  ├─ preload.js           สะพานที่ปลอดภัยระหว่างหน้าเว็บกับ Windows
│  ├─ settings.js          การตั้งค่า (โฟลเดอร์ส่งออก ไฟล์ล่าสุด)
│  ├─ updater.js           ระบบอัปเดตอัตโนมัติ
│  └─ renderer/desktop-bridge.js   ต่อเมนู/ไฟล์เข้ากับแอปเว็บ
├─ scripts/prepare-web.js  แปลง HTML ให้ใช้งานออฟไลน์ (ทำอัตโนมัติตอน build)
├─ build/                  ไอคอนโปรแกรม (icon.ico) และไอคอนไฟล์ .ycad (ycad.ico)
├─ .github/workflows/build.yml   ให้ GitHub สร้างไฟล์ .exe อัตโนมัติ
└─ package.json            ชื่อ เวอร์ชัน และการตั้งค่าตัวติดตั้ง
```

## ตั้งค่าบน GitHub ทีละขั้น (ทำครั้งเดียว)

> ใช้บัญชี GitHub เดิม (`patarakorn-bas`) ที่ใช้กับ GitHub Pages ได้เลย ไม่ต้องติดตั้งโปรแกรมอะไรในเครื่อง

### ขั้นที่ 1 — สร้าง repository ใหม่

1. เข้า <https://github.com/new>
2. **Repository name**: `yotha-cad-desktop`
   (ถ้าใช้ชื่ออื่น ต้องแก้ `"repo"` ใน `package.json` ส่วน `"publish"` ให้ตรงกัน)
3. เลือก **Public**
   - จำเป็นสำหรับระบบอัปเดตอัตโนมัติ: โปรแกรมที่ติดตั้งในเครื่องผู้ใช้ต้องอ่าน Releases ได้โดยไม่ต้องล็อกอิน
   - ถ้าเป็น Private ตัว build ยังทำงาน แต่ปุ่ม "ตรวจหาเวอร์ชันใหม่" จะขึ้นข้อผิดพลาด
4. **ไม่ต้อง**ติ๊ก Add a README / .gitignore / license (เรามีให้แล้ว)
5. กด **Create repository**

### ขั้นที่ 2 — อัปโหลดไฟล์ทั้งหมด

1. แตกไฟล์ `yotha-cad-desktop.zip` ในเครื่อง
2. ในหน้า repo ที่เพิ่งสร้าง กดลิงก์ **uploading an existing file**
3. เปิดโฟลเดอร์ `yotha-cad-desktop` ที่แตกไว้ กด **Ctrl+A** เลือกทุกอย่าง (รวมโฟลเดอร์ `.github`) แล้ว**ลากมาวาง**ในหน้าเว็บ
   - ต้องเห็นโฟลเดอร์ `.github`, `build`, `scripts`, `src`, `web` และไฟล์ `package.json`, `package-lock.json`, `README.md`, `.gitignore`
   - ถ้าโฟลเดอร์ `.github` ไม่ขึ้น: ใน File Explorer เปิด **มุมมอง → แสดง → รายการที่ซ่อน** แล้วลากใหม่
4. ช่อง Commit changes พิมพ์ `เริ่มโปรเจกต์` แล้วกด **Commit changes**
5. ตรวจว่าในหน้า repo มีไฟล์ `.github/workflows/build.yml` (กดเข้าไปดูได้)

> ทางเลือก: ใช้โปรแกรม **GitHub Desktop** (<https://desktop.github.com>) — File → Add local repository → เลือกโฟลเดอร์ → Publish repository จะสะดวกกว่าเมื่อต้องอัปเดตบ่อย

### ขั้นที่ 3 — อนุญาตให้ GitHub Actions สร้าง Release

1. ในหน้า repo ไปที่ **Settings** → เมนูซ้าย **Actions** → **General**
2. หัวข้อ **Actions permissions**: เลือก **Allow all actions and reusable workflows**
3. เลื่อนลงไปหัวข้อ **Workflow permissions**: เลือก **Read and write permissions** → กด **Save**

### ขั้นที่ 4 — สร้างไฟล์ติดตั้งครั้งแรก

1. ไปแท็บ **Actions** (ถ้าขึ้นปุ่ม *I understand my workflows, go ahead and enable them* ให้กดก่อน)
2. คลิก **Build Windows installer** ทางซ้าย
3. กดปุ่ม **Run workflow** (ด้านขวา) →
   - **เลขเวอร์ชัน**: `8.8.0` (ตรงกับเว็บ v8.8 — ดูหัวข้อ “หลักการตั้งเลขเวอร์ชัน”)
   - **ดึงไฟล์ HTML ล่าสุดจากเว็บ**: ไม่ต้องติ๊กในครั้งแรก
   - กด **Run workflow** สีเขียว
4. รอประมาณ 6–12 นาที (กดเข้าไปดูความคืบหน้าได้) จนขึ้นเครื่องหมาย ✅ สีเขียว
5. ไปที่หน้าแรกของ repo → ด้านขวาหัวข้อ **Releases** → จะเห็น **v8.8.0** มีป้าย **Draft** (ฉบับร่าง)
   → ดาวน์โหลด `YothaCAD-Setup-8.8.0.exe`
   - ฉบับร่างมองเห็นเฉพาะเจ้าของ repo ยังไม่มีใครได้รับอัปเดต
6. ติดตั้งและทดสอบตาม **ขั้นที่ 5** และ **รายการทดสอบก่อนปล่อย** ด้านล่าง
7. ถ้าผ่าน: หน้า Releases → กด ✏️ (Edit) ที่ v8.8.0 → พิมพ์รายละเอียดการเปลี่ยนแปลง → ติ๊ก **Set as the latest release** → กด **Publish release**
   - ไฟล์ `latest.yml` และ `.blockmap` ใน Release **ห้ามลบ** — ระบบอัปเดตใช้ไฟล์เหล่านี้

### ขั้นที่ 5 — ติดตั้งบน Windows

1. ดับเบิลคลิก `YothaCAD-Setup-8.8.0.exe`
2. ถ้าขึ้นหน้าจอสีน้ำเงิน **Windows protected your PC** (เพราะโปรแกรมยังไม่ได้ซื้อใบรับรองลงนามโค้ด):
   กด **More info / ข้อมูลเพิ่มเติม** → **Run anyway / เรียกใช้อยู่ดี**
3. เลือกโฟลเดอร์ติดตั้ง (ค่าเริ่มต้นไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ) → Install
4. จะมีไอคอน **โยธาแคด** ในเมนู Start และบนเดสก์ท็อป คลิกขวาที่ไอคอนบนทาสก์บาร์ → **ปักหมุดไปที่แถบงาน** ได้
5. ไฟล์ `.ycad` จะแสดงไอคอนของโยธาแคด และดับเบิลคลิกเปิดได้ทันที

## หลักการตั้งเลขเวอร์ชัน

ให้เลขของตัว Windows **ตรงกับเวอร์ชันเว็บ** จะได้รู้ทันทีว่าคู่กัน

| สถานการณ์ | เวอร์ชันเว็บ | เวอร์ชัน Windows |
|---|---|---|
| ครั้งแรก | v8.8 | **8.8.0** |
| เว็บออกเวอร์ชันใหม่ | v8.9 | **8.9.0** |
| แก้เฉพาะฝั่ง Windows (เมนู ไอคอน ตัวติดตั้ง) หรือเว็บแก้บั๊กโดยไม่เปลี่ยนเลข | v8.9 | **8.9.1**, 8.9.2 … |
| เว็บขึ้นเลขหลักใหม่ | v9.0 | **9.0.0** |

- เลขใหม่ต้อง**สูงกว่า**ที่เคย Publish เสมอ (ลดเลขลงไม่ได้ ไม่งั้นเครื่องผู้ใช้จะไม่อัปเดต)
- ถ้าใส่เลขไม่ตรงกับเว็บ workflow จะขึ้นคำเตือนสีเหลือง ⚠ แต่ยัง build ให้ตามปกติ

## เมื่อเวอร์ชันเว็บมีการอัปเดต → ออกเวอร์ชัน Windows ใหม่

### 1) สร้างฉบับร่าง — เลือกทางใดทางหนึ่ง

**ทาง A — ให้ GitHub ดึงจากเว็บเอง (ง่ายที่สุด)**
ใช้เมื่ออัปโหลดเวอร์ชันใหม่ขึ้น GitHub Pages (`https://patarakorn-bas.github.io/yotha-cad/`) เรียบร้อยแล้ว

1. แท็บ **Actions** → **Build Windows installer** → **Run workflow**
2. **เลขเวอร์ชัน**: ตามตารางด้านบน เช่น เว็บ v8.9 → `8.9.0`
3. ✅ ติ๊ก **ดึงไฟล์ HTML ล่าสุดจากเว็บ**
4. Run workflow → รอจนเสร็จ (GitHub จะบันทึก HTML ใหม่ลงโฟลเดอร์ `web/` ให้ด้วย)

**ทาง B — อัปโหลดไฟล์ HTML เอง**
1. ใน repo เปิดโฟลเดอร์ `web/` → กดไฟล์ HTML เดิม → ปุ่ม ⋯ → **Delete file** → Commit
2. ในโฟลเดอร์ `web/` → **Add file → Upload files** → ลากไฟล์ HTML ใหม่ (ชื่ออะไรก็ได้ เช่น `yotha-cad-v8.9.html`) → Commit
3. Actions → Run workflow → ใส่เลขเวอร์ชัน (**ไม่ต้อง**ติ๊กดึงจากเว็บ)

> โฟลเดอร์ `web/` ต้องมีไฟล์ .html **ไฟล์เดียว** ถ้ามีหลายไฟล์ การ build จะหยุดและแจ้งเตือน

### 2) ทดสอบฉบับร่าง (ประมาณ 5 นาที)

ดาวน์โหลด Setup.exe จากฉบับร่างในหน้า Releases แล้วติดตั้งทับเวอร์ชันเดิมได้เลย จากนั้นไล่ตามนี้

**รายการทดสอบก่อนปล่อย**
- [ ] เปิดโปรแกรมได้ หน้าจอและตัวอักษรไทยแสดงปกติ ภาพ 3D ขึ้น
- [ ] **ช่วยเหลือ → เกี่ยวกับโยธาแคด** แสดงเลขเวอร์ชันใหม่ และ “ตัวแอป” ตรงกับเวอร์ชันเว็บ
- [ ] ดับเบิลคลิกไฟล์ `.ycad` งานจริงที่มีอยู่ → เปิดได้ ข้อมูลครบ
- [ ] แก้ไขเล็กน้อย → ชื่อหน้าต่างขึ้น ● → Ctrl+S → ● หายไป
- [ ] ไฟล์ → ส่งออก: **PDF**, **DXF**, **BOQ Excel**, **IFC** ได้ไฟล์ครบ และเปิดในโปรแกรมปลายทางได้
- [ ] ปิดอินเทอร์เน็ต (Wi-Fi) แล้วลองเปิดโปรแกรมและส่งออก Excel อีกครั้ง → ยังใช้ได้
- [ ] เมนู แก้ไข → เลิกทำ / มุมมอง → 3D ทำงาน

### 3) ปล่อยให้ผู้ใช้
- **ผ่าน** → หน้า Releases → ✏️ Edit → เขียนสิ่งที่เปลี่ยน (ข้อความนี้จะแสดงในกล่องแจ้งอัปเดต) → **Publish release**
- **ไม่ผ่าน** → แก้ไข (เช่น อัปโหลด HTML ที่แก้แล้ว) แล้ว **Run workflow ด้วยเลขเดิม** ได้เลย ฉบับร่างเดิมจะถูกแทนที่ ไม่ต้องขยับเลข
- ไม่ต้องการเวอร์ชันนี้แล้ว → ✏️ Edit → **Delete** ฉบับร่างทิ้งได้ (ยังไม่มีใครได้รับ)

### ผู้ใช้จะได้รับอัปเดตอย่างไร (หลังกด Publish)
- เปิดโปรแกรม → ประมาณ 8 วินาทีจะตรวจหาเวอร์ชันใหม่ (และตรวจซ้ำทุก 6 ชั่วโมง)
- ขึ้นกล่อง “มีเวอร์ชันใหม่” → **ดาวน์โหลด** (ทำงานต่อได้ระหว่างโหลด เห็นแถบความคืบหน้าบนไอคอนทาสก์บาร์)
- โหลดเสร็จ → **ติดตั้งและเปิดใหม่** (โปรแกรมถามบันทึกงานก่อนปิด) หรือ **ติดตั้งเมื่อปิดโปรแกรม**
- ตรวจเองได้ที่ **ช่วยเหลือ → ตรวจหาเวอร์ชันใหม่**

## การใช้งานโปรแกรม

| เมนู | คำสั่ง |
|---|---|
| **ไฟล์** | โครงการใหม่ (Ctrl+N), หน้าต่างใหม่ (Ctrl+Shift+N), เปิด (Ctrl+O), เปิดล่าสุด, นำเข้าจากเวอร์ชันเว็บ (.json), บันทึก (Ctrl+S), บันทึกเป็น (Ctrl+Shift+S), ส่งออก ▸, ปิดหน้าต่าง (Ctrl+W) |
| **ไฟล์ → ส่งออก** | PDF ทุกแผ่นงาน (Ctrl+P), PDF แผ่นที่เปิด, DXF (.zip), BOQ Excel, IFC, CSV, PNG แปลน/3D/4K, สคริปต์ Revit, *ถามตำแหน่งบันทึกทุกครั้ง*, เลือกโฟลเดอร์ส่งออก, เปิดโฟลเดอร์ส่งออก |
| **แก้ไข** | เลิกทำ (Ctrl+Z), ทำซ้ำ (Ctrl+Y), ตัด/คัดลอก/วาง, เลือกทั้งหมดในชั้น (Ctrl+A), ยกเลิกคำสั่ง (Esc), ลบที่เลือก (Delete) |
| **มุมมอง** | 2D / 2D+3D / 3D / รูปตัด / แผ่นงาน (Ctrl+1…5), มุมกล้อง 3D, ซูมพอดีจอ, แผงด้านข้าง (Ctrl+B), สลับธีม, ขยาย/ย่อตัวอักษร, เต็มจอ (F11) |
| **หน้าต่าง** | สลับระหว่างหน้าต่างที่เปิดอยู่ |
| **ช่วยเหลือ** | คู่มือ (F1), ตรวจหาเวอร์ชันใหม่, เกี่ยวกับโยธาแคด |

**ส่งออกลงโฟลเดอร์โดยตรง:** ไฟล์ → ส่งออก → *เลือกโฟลเดอร์ส่งออก…* แล้ว**เอาติ๊ก** *ถามตำแหน่งบันทึกทุกครั้ง* ออก
ไฟล์จะถูกบันทึกลงโฟลเดอร์นั้นทันที (ถ้าชื่อซ้ำจะเติม “(2)”, “(3)” ให้) และมีปุ่ม **เปิดโฟลเดอร์** มุมขวาล่าง

**ย้ายงานจากเวอร์ชันเว็บ:** ในเวอร์ชันเว็บ เมนู ไฟล์ → *ส่งออกโครงการนี้ (.json)* (หรือ จัดการโครงการ → ส่งออก ทีละโครงการ)
แล้วในโปรแกรม Windows: ไฟล์ → *นำเข้าโครงการจากเวอร์ชันเว็บ (.json)…* (เลือกหลายไฟล์พร้อมกันได้) → กด Ctrl+S เพื่อบันทึกเป็น `.ycad`

**ไฟล์ .ycad** เป็นข้อมูล JSON รูปแบบเดียวกับไฟล์ส่งออกของเวอร์ชันเว็บ ถ้าต้องการเปิดในเวอร์ชันเว็บ ให้เปลี่ยนนามสกุลเป็น `.json` แล้วใช้ “นำเข้าโครงการ”

**การกู้คืนงาน:** งานถูกเก็บอัตโนมัติภายในโปรแกรมตลอดเวลา ถ้าไฟดับหรือโปรแกรมค้าง เมื่อเปิดไฟล์ `.ycad` เดิมครั้งถัดไป โปรแกรมจะถามว่าจะ *กู้คืนงานที่ยังไม่ได้บันทึก* หรือไม่

**ข้อมูลโปรแกรม** (การตั้งค่า, ไฟล์ล่าสุด, โครงการภายใน) อยู่ที่ `%APPDATA%\YothaCAD` — ถอนการติดตั้งแล้วข้อมูลยังอยู่

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| Actions ขึ้น ❌ ขั้น “สร้างไฟล์ติดตั้งและออก Release” มีคำว่า `403` หรือ `Resource not accessible by integration` | ทำขั้นที่ 3 (Read and write permissions) แล้ว Run ใหม่ |

| ❌ “โฟลเดอร์ web/ มีไฟล์ .html หลายไฟล์” | ลบไฟล์เก่าออกจาก `web/` ให้เหลือไฟล์เดียว |

| ⚠ เหลือง “เลขเวอร์ชันไม่ตรงกับเว็บ” | แค่คำเตือน — ตรวจว่าใส่เลขถูกตามตาราง “หลักการตั้งเลขเวอร์ชัน” |
| โปรแกรมไม่แจ้งอัปเดต | Release ยังเป็น **Draft** อยู่ (ต้องกด Publish), repo ต้องเป็น Public, เลขใหม่ต้องสูงกว่าที่ติดตั้ง, ใน Release ต้องมี `latest.yml` |
| ขั้น prepare-web ขึ้น ⚠ “ยังมีไฟล์ที่โหลดจากอินเทอร์เน็ต” | HTML เวอร์ชันใหม่เพิ่มไลบรารีจาก CDN — ดูหัวข้อ “ถ้าเวอร์ชันเว็บเพิ่มไลบรารีใหม่” |
| เมนูบางอย่างไม่ทำงานหลังเปลี่ยน HTML | เปิด ช่วยเหลือ → สำหรับนักพัฒนา → เครื่องมือนักพัฒนา ดูแท็บ Console ว่ามีข้อความ `[โยธาแคด desktop]` แจ้งชื่อที่หายไปหรือไม่ |

## ข้อตกลงกับแอปเวอร์ชันเว็บ (ส่งให้แชทที่พัฒนาเวอร์ชันเว็บ)

`desktop-bridge.js` เรียกใช้ชื่อเหล่านี้ในแอปเว็บ **ถ้าจะเปลี่ยนชื่อ ให้แก้ bridge ตามด้วย**

- ตัวแปรระดับบนสุด: `S`, `cur`, `projId`
- ฟังก์ชัน: `saveFile(name, data)` *(ทุกการส่งออกต้องผ่านฟังก์ชันนี้)*, `importAsProject`, `newProject`, `openProject`, `pIndex`, `pLoad`, `pWrite`, `pSaveCurrent`, `fixCur`, `resetSession`, `changed`, `undo`, `redo`, `toast`
- ปุ่ม/ตัวเลือก: `#menu button[data-m=…]` (`proj`, `dxf`, `ifc`, `boq`, `csv`, `png2`, `png3`, `png3k4`, `rvt`, `theme`), `#viewSeg button[data-v=…]`, `[data-cam=…]`, `#zfit`, `#sideB`, `#helpB`, `#hPdf`, `#hPdf1`, `#bqXl`
- ไลบรารี: Three.js โหลดด้วย `<script src=".../three.js/rNNN/three.min.js">`, ExcelJS โหลดผ่าน `loadXJ()` ที่ลอง `exceljs.min.js` ในโฟลเดอร์เดียวกันก่อน, ฟอนต์ผ่านลิงก์ Google Fonts `css2?family=…`
- แอปเว็บรู้ได้ว่ากำลังรันในโปรแกรม Windows จาก `window.ycadDesktop` หรือ `<meta name="yothacad-desktop">`

### ถ้าเวอร์ชันเว็บเพิ่มไลบรารี/ฟอนต์ใหม่
- **ฟอนต์ Google ใหม่**: เพิ่มแพ็กเกจ `@fontsource/ชื่อฟอนต์` ใน `devDependencies` ของ `package.json` (เช่น `"@fontsource/kanit": "5.3.0"`) — `prepare-web.js` จะแปลงให้อัตโนมัติ
- **เปลี่ยนรุ่น Three.js**: แก้ `"three"` ใน `package.json` เป็น `0.NNN.0` (เช่น r150 → `0.150.0`)
- **ไลบรารี CDN อื่น**: เพิ่มแพ็กเกจ npm แล้วเพิ่มบรรทัดคัดลอก/แทนที่ URL ใน `scripts/prepare-web.js` แบบเดียวกับ ExcelJS

## สำหรับนักพัฒนา (ไม่บังคับ — รันในเครื่องตัวเอง)

ต้องมี Node.js 22 ขึ้นไป

```bash
npm install          # ครั้งแรก
npm start            # รันโปรแกรมทดสอบ (ใช้ HTML ใน web/)
npm run dist         # สร้าง dist/YothaCAD-Setup-x.y.z.exe ในเครื่อง (ไม่อัปโหลด)
```

- ระบบอัปเดตทำงานเฉพาะโปรแกรมที่ติดตั้งจาก Setup.exe
- โปรแกรมยังไม่ได้ลงนามดิจิทัล (code signing) Windows จึงเตือนตอนติดตั้งครั้งแรก ถ้าต้องการตัดคำเตือน ต้องซื้อใบรับรอง (เช่น Azure Trusted Signing หรือ OV/EV certificate) แล้วตั้งค่า `win.azureSignOptions` หรือ `CSC_LINK` ใน workflow
